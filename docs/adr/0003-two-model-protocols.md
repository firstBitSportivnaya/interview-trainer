# Ключ говорит одним из двух протоколов

Нужны ключ Клода, ключ DeepSeek и любой другой ключ той же формы. Запись ключа состоит из протокола, базового адреса, имени модели и секрета. Протокола два: родной протокол Anthropic и протокол, совместимый с OpenAI. Отдельный протокол на каждого поставщика не заводим. Сессия помнит, каким ключом она шла.
