# Сессия читает утверждённое досье

Исходные файлы дела — таблицы, презентации и протоколы. Отдать их персонажу целиком нельзя: слои смешаются, а правка человека потеряется. Сессия читает только утверждённое досье. Сборщик готовит черновик по карте файлов, в диалог текст попадает после вычитки. Новый файл входит в следующую сессию после нового черновика и новой вычитки. Открытая сессия до конца держит досье, с которым её открыли.

Рассматривали поиск по сырым файлам на каждом ходе. Так слой и вычитка негде закрепить.
