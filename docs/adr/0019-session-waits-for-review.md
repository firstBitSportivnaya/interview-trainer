# Сессия ждёт разбора

Разбор одной открытой сессии может срываться повторно. Сессию без разбора не закрывают. Сессия закончена, только когда разбор записан.

Один способ снова провести сессию той же тройки «проект + роль исполнителя + исполнитель»: владелец повторяет разбор этой открытой сессии, пока он не запишется. Успешный разбор заканчивает сессию. Индекс одной открытой сессии на тройку после этого её не держит, и следующую сессию той же тройки можно открыть.

Пока разбор не записан, сессия остаётся открытой. Вторая открытая сессия той же тройки не создаётся. Сбой разбора ход подготовки не меняет. Ход подготовки не становится фактом досье (ADR-0002).

Закрыть сессию без разбора нельзя.
