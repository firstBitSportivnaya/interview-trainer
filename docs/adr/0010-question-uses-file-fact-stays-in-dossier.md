# Вопрос опирается на текст файла, факт берётся из досье

Сессия произносит факты только из утверждённого досье. Чтобы вопрос был точнее, персонаж смотрит текст файлов своего слоя: заказчик — материал проекта, внутренняя команда — материал проекта и служебный слой. Шпаргалка проекта в этот поиск не входит. Найденный фрагмент уточняет вопрос и не произносится. Расхождение речи с текстом файла видит разбор.

В ADR-0001 поиск по сырым файлам на каждом ходе отклонили: слой и правка человека были негде закрепить. Поиск остаётся внутри уже названного слоя и досье не подменяет. Вкладывать в ход все файлы целиком тоже не стали: десятки документов в окно модели не входят.
