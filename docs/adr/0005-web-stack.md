# Стек веба

Заменён ADR-0017.

Веб остаётся адаптером над ядром и не входит в ядро. Страницы собирает Hono серверным JSX, ход страницы ведёт htmx. Ответ модели в сессии идёт потоком по SSE.

Рассматривали страницы без фреймворка, Fastify, Next.js и Python/FastAPI. Без фреймворка формы и поток расползаются по обработчикам. Fastify не даёт разметку. Next.js тащит отдельный браузерный контур. Python/FastAPI разводит ядро и веб по двум языкам.
