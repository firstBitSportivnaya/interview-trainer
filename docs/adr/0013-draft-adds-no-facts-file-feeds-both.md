# Черновик не добавляет фактов, файл кормит и черновик, и поиск

Короткий черновик содержит только то, что было в тексте файлов. Факт, которого в файлах нет, черновиком не становится. Владелец правит собранное и утверждает.

Файл с названным слоем и извлечённым текстом входит и в черновик, и в поиск. Отдельно выключить одно из двух нельзя. Не подтверждённый слой не входит ни туда, ни туда.

Рассматривали свободный пересказ и два тумблера на файл. Пересказ закрепляет выдумку в досье. Тумблеры расходятся: вопрос опирается на файл, который в досье не пускали.
