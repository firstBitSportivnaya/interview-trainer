# Черновик не добавляет фактов, файл кормит и черновик, и поиск

Короткий черновик содержит только то, что было во вставленном тексте и в тексте файлов. Факт, которого в этих источниках нет, черновиком не становится. Удерживают это просьба сборщику и правка владельца перед утверждением.

Файл с названным слоем и извлечённым текстом входит в черновик. В поиск он входит по правилу следующей версии: эта версия файлы на сессии не ищет. Отдельно выключить одно из двух нельзя. Не подтверждённый слой не входит ни туда, ни туда.

Рассматривали свободный пересказ и два тумблера на файл. Пересказ закрепляет выдумку в досье. Тумблеры расходятся: вопрос опирается на файл, который в досье не пускали.
