# Хранилище SQLite

Проекты, досье, сессии, ход подготовки и ключи лежат в SQLite через встроенный `node:sqlite`, на машине владельца. Одна открытая сессия на тройку «проект + роль исполнителя + исполнитель» держится уникальным индексом. Ключи переезжают из `data/keys.json`.

Рассматривали отдельные JSON-файлы. Так правило одной открытой сессии негде закрепить, а ключи живут в стороне от остальных записей.
