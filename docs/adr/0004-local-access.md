# Доступ первой версии: локальный веб и список Telegram

Тренажёр хранит служебный слой чужих компаний. Веб первой версии слушает только машину владельца, без пароля. Бот отвечает только внесённым Telegram-id. Чужой id получает пустой ответ, досье ему не открывается. Мини-приложения нет. Дела, досье, сессии и секреты остаются на машине владельца и в репозиторий не входят.

Общий сервис с регистрацией отложен до пробы на одном владельце. Место под владельца и исполнителя в записях уже есть: у хода подготовки ключ включает исполнителя.
