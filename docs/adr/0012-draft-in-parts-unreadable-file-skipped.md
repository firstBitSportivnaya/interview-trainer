# Черновик собирается частями, нечитаемый файл пропускается

Короткий черновик слоя собирается из файлов частями: файл или небольшая пачка, не все документы одним запросом. Полный текст остаётся у файла и служит поиску. Утверждает по-прежнему владелец.

Файл, из которого текст не извлекается, сохраняется и в черновик и в поиск не входит. Сборщик текст не выдумывает. Владелец видит, что файл не прочитан. Распознавание скана и картинки — задача на развитие, не эта версия.

Рассматривали отправить все файлы одним запросом. Десятки документов в окно модели не входят.
