# Черновик собирается частями, нечитаемый файл пропускается

Короткий черновик слоя собирается из файлов частями: файл или небольшая пачка, не все документы одним запросом. Полный текст остаётся у файла и служит поиску. Утверждает по-прежнему владелец. Сборка частями — правило следующей версии. Эта версия отправляет черновик слоя одним запросом.

Файл, из которого текст не извлекается, в черновик и в поиск не входит. Сборщик текст не выдумывает. Хранить такой файл и показывать владельцу, что он не прочитан, — правило следующей версии. Эта версия файл без текста не записывает. Распознавание скана и картинки — задача на развитие, не эта версия.

Рассматривали отправить все файлы одним запросом. Десятки документов в окно модели не входят.
