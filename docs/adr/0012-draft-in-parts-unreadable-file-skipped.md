# Черновик собирается частями, непрочитанный файл в него не входит

Фраза «распознавателя нет» заменена: скан читается на машине владельца. Сборка черновика одним запросом не заменена и совпадает с кодом.

Короткий черновик слоя собирается из файлов частями: файл или небольшая пачка, не все документы одним запросом. Полный текст остаётся у файла. Текст, снятый не с картинки, служит поиску. Утверждает по-прежнему владелец. Сборка частями — правило следующей версии. Эта версия отправляет черновик слоя одним запросом.

Файл, из которого текст не извлекается, в черновик и в поиск не входит. Сборщик и чтение файла текст не выдумывают. Пустой текст записывается без текста и без слоя: владелец видит, что файл не прочитан. Эта запись в черновик и в поиск не входит.

Скан pdf и отдельная картинка распознаются на машине владельца. Файл заказчика на чужую службу распознавания не уходит. Надпись становится извлечённым текстом и входит в черновик слоя, который назвал владелец. Картинка без надписи и скан без надписи остаются без текста. Слайд pptx из рисунка и лист xlsx из картинок остаются непрочитанными. Распознанный текст в поиск этой поставки не входит. Для поиска скана остаётся правило ADR-0016. Пока локального распознавателя нет, надпись не появляется и абзац не сочиняется.

Рассматривали не записывать файл без текста вовсе и отправить все файлы одним запросом. Без записи владельцу не на что показать, что файл не прочитан. Десятки документов в окно модели не входят.
