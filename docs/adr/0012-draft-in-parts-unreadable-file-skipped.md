# Черновик собирается частями, непрочитанный файл в него не входит

Короткий черновик слоя собирается из файлов частями: файл или небольшая пачка, не все документы одним запросом. Полный текст остаётся у файла и служит поиску. Утверждает по-прежнему владелец. Сборка частями — правило следующей версии. Эта версия отправляет черновик слоя одним запросом.

Файл, из которого текст не извлекается, в черновик и в поиск не входит. Сборщик и чтение файла текст не выдумывают. Пустой текст и файл без текстового слоя записываются без текста и без слоя: владелец видит, что файл не прочитан. Эта запись в черновик и в поиск не входит. Распознавание скана и картинки остаётся задачей на развитие.

Рассматривали не записывать файл без текста вовсе и отправить все файлы одним запросом. Без записи владельцу не на что показать, что файл не прочитан. Десятки документов в окно модели не входят.
