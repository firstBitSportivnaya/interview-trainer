# Факты дела и ход подготовки пишутся раздельно

Реплика исполнителя на сессии может быть ошибкой. Запись этой реплики в материал дела сделает ошибку словом заказчика для следующей сессии. Ход подготовки копится по тройке «дело + роль исполнителя + исполнитель» и говорит, куда давить. Пробел закрывается, когда поздний разбор видит, что пункт пройден. Сигнал следить и расхождение остаются, пока исполнитель сам их не снимет. Материал дела и служебный слой меняются только принятой правкой. Персонаж заказчика получает из хода линию поведения без текста служебного слоя. Персонаж внутренней команды читает запись целиком.
