# Локальный индекс фрагментов файла

Следующая версия на ходе ищет фрагмент. Индекс считается на установке моделью multilingual-e5-small, без внешнего API. Векторы другой модели в тот же поиск не входят. Файл попадает в поиск после полного набора векторов; пустой и нечитаемый текст готовым не считается. Первая поставка этого поиска читает DOCX, PPTX, XLSX, TXT и PDF. Скан остаётся распознаванием на машине владельца и в эту поставку не входит. Открытая сессия ищет тексты, с которыми её открыли. В выдаче только свой проект и слой персонажа; шпаргалка проекта в поиск не входит. Факт произносит досье: фрагмент уточняет вопрос и вслух не произносится, спорный с досье своего слоя персонажу не отдаётся. Разбор баллов не ставит. Пока замер не показал нужду, поиск — полный перебор векторов проекта в SQLite. Транзакция хранилища не держится на извлечении текста и на расчёте векторов.

Рассматривали внешний API эмбеддингов, векторное расширение SQLite, полнотекстовый гибрид и балльную оценку по фрагментам. Внешний API уносит файл с установки. Расширение и гибрид не входят, пока полный перебор укладывается в ход. Балл подменяет разбор. Смешение векторов при смене модели даёт соседство несравнимых чисел.
