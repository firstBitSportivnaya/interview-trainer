# Несколько исполнителей на одной установке

Конец пути — несколько исполнителей на установке владельца. Владелец заводит проекты, слои, ключи и назначение. Исполнитель открывает сессию только по назначенному проекту; профиль и ход подготовки у него свои. Владелец проходит сессию по любому своему проекту без отдельного назначения. Ключи остаются ключами установки, у сессии по-прежнему один ключ, протокола два. Отзыв назначения не закрывает уже открытую сессию; новая сессия по этому проекту у этого исполнителя не открывается. Первая версия по-прежнему один исполнитель — владелец. Ядро не запрещает другого исполнителя. Публичного хостинга нет: файлы и сессии остаются на машине владельца.

Рассматривали несколько владельцев, общую учётную запись и публичную регистрацию. Несколько владельцев делят проекты и ключи, которые уже собраны на одной установке. Общая учётная запись стирает ход подготовки конкретного человека. Регистрация выносит служебный слой с машины владельца.
