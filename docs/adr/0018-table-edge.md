# Связь таблицы

Заменяет в ADR-0011 фразу «граф не входит».

Ребро берётся только из файла таблицы. Это заголовки первой строки, если их не меньше двух и ниже есть значение. Абзац и pdf ребра не дают. Связь уточняет вопрос, число из таблицы не произносится. Досье сильнее файла: связь, которая спорит с утверждённым текстом своего слоя, персонажу не отдаётся. Фрагмент не произносится как факт.

Рассматривали граф по всей прозе. Связь в прозе сборщик выдумает. Таблица уже задаёт заголовки.
