# Секреты ключей шифруются средствами ОС

Секрет ключа попадает на диск только в виде, который читает учётная запись владельца: DPAPI на Windows, keychain на macOS. Открытого текста в `data/` нет. Это уточняет ADR-0004: локальность сама по себе секрет не прячет, а режим файла `0o600` на Windows не действует.

Рассматривали файл только для владельца и отдельный пароль на тренажёр. Режим файла на Windows других не отсекает, а пароль спорит с дверью через учётную запись машины.
