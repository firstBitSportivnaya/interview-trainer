# Слой файла называет владелец

Сборщик готовит черновик по карте файлов. Слой каждого файла называет владелец. Сборщик может показать догадку, но без подтверждения файл ни в один слой не входит. Имя файла слой не задаёт.

Рассматривали назначать слой по имени и содержимому, чтобы не спрашивать владельца. Ошибочный слой отдал бы служебный текст персонажу заказчика.
