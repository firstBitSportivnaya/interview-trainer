# Досье сильнее файла, граф отложен

Фрагмент файла, который спорит с утверждённым текстом своего слоя, персонажу не отдаётся. Деталь, о которой досье молчит, может уточнить вопрос.

В ход попадают короткие фрагменты, близкие по смыслу к разговору. Файл целиком не вкладывается. Граф связей по всем файлам в эту версию не входит: связь в прозе сборщик выдумает. Граф остаётся задачей на развитие и уместен там, где связь уже задана таблицей.
