# Досье сильнее файла, граф отложен

Фраза «эта версия не ищет» и «короткие фрагменты в ход не кладёт» заменена ADR-0016. Фраза «граф не входит» заменена ADR-0018. Досье сильнее файла. Фрагмент не произносится.

Фрагмент файла, который спорит с утверждённым текстом своего слоя, персонажу не отдаётся. Деталь, о которой досье молчит, может уточнить вопрос.

В ход попадают короткие фрагменты, близкие по смыслу к разговору. Файл целиком не вкладывается. Короткие фрагменты на ходе — правило следующей версии. Эта версия их в ход не кладёт. Граф связей по всем файлам в эту версию не входит: связь в прозе сборщик выдумает. Граф остаётся задачей на развитие и уместен там, где связь уже задана таблицей.
