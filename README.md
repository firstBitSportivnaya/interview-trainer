# Тренажёр собеседований

Установка на машине владельца.

```
npm ci
npm start
```

Страница открывается по адресу http://127.0.0.1:4173.

Веса модели лежат в `data/models/multilingual-e5-small`. Данные tesseract — в `data/models/tesseract`, файл `rus.traineddata`.

Без весов поиск фрагментов выключен.

Скачать веса и данные распознавания в эти каталоги:

```
npm run fetch-models
```

`npm run verify` этот скрипт не запускает. Каталог `data/` в git не входит: веса модели и данные tesseract в коммит не попадают.
