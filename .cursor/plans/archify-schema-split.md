|---|---|---|---|
| 1 | Разведка пути сессии: веб, ядро, хранилище, ключ, модель, эмбеддинги | dsh headless | отчёт, не больше 6 файлов и 8 пунктов «путь:строка». run_id run-67aae51c-b9a9-4faa-bb81-3e1a2b161b8f |
| 2 | Кандидат architecture и `finalize` | родитель | квитанция finalize |
| 3 | Ревью диффа перед pull request | dsh review | замечания или «замечаний нет» |
| 4 | Коммит, push, pull request | родитель | ссылка на pull request |
