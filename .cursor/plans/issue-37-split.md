# Issue 37 — локальная модель эмбеддингов

Шов адаптера — `localEmbeddings`: установка считает вектор сама. Перед текстом файла префикс `passage: `, перед текстом хода — `query: `. Среднее по токенам, норма L2 равна 1, длина 384. Сеть запрещена. Живые веса в проверку не входят.

Шов ядра — `openTrainer`: записанный порт, текст во входе персонажа. Чужие векторы в сравнение не входят, смена имени модели строит новый индекс. Нулевой вектор и длина не 384 не делают файл готовым. Сохранённый вектор нормирован. Проверки ядра живую модель не вызывают.
