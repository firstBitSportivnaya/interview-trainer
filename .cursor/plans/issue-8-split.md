# Issue 8 — разбиение

Исполнитель заканчивает сессию на вебе. Разбор пишет тот же ключ. Текст называет прозвучавшее служебное, расхождение с досье, расхождение с текстом файла проекта и незаданные вопросы шпаргалки проекта. Числовой оценки нет. Сбой оставляет стенограмму и не меняет ход подготовки. Успешный разбор ход тоже не пишет: закрытие пробела по ADR-0002 в эту задачу не входит.

Швы: `finishSession` / `readReview` ядра и `POST /sessions/:id/finish` плюс страница сессии. Блоки ядра и веба — у родителя: это смысл критериев, не массовая правка.

| № | Блок | Исполнитель | Проверка |
|---|---|---|---|
| 1 | Ядро: закончить сессию, разбор тем же ключом, стенограмма, ход не меняется | родитель | `node --test test/review.test.ts` |
| 2 | Веб: закончить сессию, текст разбора, перечитать стенограмму, сбой | родитель | `node --test test/web.test.ts` |
| 3 | Полный гейт | родитель | `npm run verify` |
| 4 | Ревью diff | родитель, субагент pr-review | список замечаний |

| Критерий | Тест | Негатив |
|---|---|---|
| Сессию можно закончить на вебе | `test/web.test.ts` | чужая сессия — 404, форма вопроса у законченной нет |
| Разбор идёт тем же ключом | `test/review.test.ts` | второй ключ в вызов не входит |
| Разбор называет служебное, расхождение с досье и с текстом файла, незаданные вопросы шпаргалки проекта | `test/review.test.ts` | поздний файл и новое досье в разбор не входят |
| Числовой оценки нет | `test/review.test.ts`, `test/web.test.ts` | у результата нет поля оценки, на странице нет поля балла |
| Стенограмму законченной сессии можно перечитать | `test/review.test.ts`, `test/web.test.ts` | нет сессии — записи нет |
| Сбой разбора сохраняет стенограмму и не пишет ход подготовки | `test/review.test.ts`, `test/web.test.ts` | успешный разбор ход тоже не пишет |
| Проверка идёт через ядро со записанной моделью | оба файла | живой порт не подставляется |
