# Issue 43 — поведение персонажа с живым ключом

Швы: сверка реплики (`src/character-check.ts`) и команда, которая читает ключ установки и зовёт живой порт. В `npm run verify` команда не входит. Записанный порт в `test/` по-прежнему доказывает только вход.

Дословное вхождение строки слоя, шпаргалки проекта и фрагмента. Отсутствующий факт — фраза `ABSENT_FACT`, без строк других фактов открытого слоя и без заданной строки, которой в досье нет.

| № | Блок | Исполнитель | Чем проверяется |
|---|---|---|---|
| 1 | Сверка реплики: служебный слой, шпаргалка проекта, отсутствующий факт, фрагмент | родитель | `node --test test/character-check.test.ts` |
| 2 | Фрагмент отмечается пройденным, только если ядро положило его во вход | родитель | `node --test test/character-check.test.ts` |
| 3 | Ключ читается из хранилища, список ключей секрет не отдаёт | родитель | `node --test test/character-check.test.ts` |
| 4 | Команда вне `npm test` и `npm run verify`, сессия не в репозитории | родитель | `node --test test/character-check.test.ts` |
| 5 | Полная проверка | родитель | `npm run verify` |

Блоки 1–5 у родителя. Смысл критериев в сверке реплики, а дословный вывод `npm run verify` нужен в теле pull request.
