# Issue 35 — спор фрагмента с досье

Шов — ядро `openTrainer`: текст, который уходит в записанную модель на ходе персонажа. Записанный порт эмбеддингов решает близость. Живой модели нет. Спор читается по тексту фрагмента и досье того же слоя, не по вектору.

Критерии — комментарий к #35. Числа из входа не выбрасываются: записанная модель проверяет текст входа.

| # | Блок | Исполнитель | Чем проверяется |
|---|---|---|---|
| 1 | Фрагмент «ограничения по весу нет» при досье «ограничение есть» во вход не входит. Фрагмент того же файла, который с досье не спорит, остаётся. Другой максимальный вес, чем в досье, тоже не входит | родитель | `node --test test/fragment.test.ts` |
| 2 | Два файла одного слоя с разным максимальным весом, досье о числе молчит: во входе оба числа и сказано не произносить ни одно как факт. В материале проекта этих чисел нет | родитель | `node --test test/fragment.test.ts` |
| 3 | Один файл называет вес, второй о весе молчит, досье молчит: фрагмент с весом может попасть во вход, и сказано не произносить его как факт. Фразы про разные числа нет | родитель | `node --test test/fragment.test.ts` |
