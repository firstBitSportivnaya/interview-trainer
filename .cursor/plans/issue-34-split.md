# Issue 34 — профиль исполнителя

Шов — ядро `openTrainer`: текст, который уходит в модель при вопросе персонажа заказчика. Отметка «портфолио уже отправлено» и сторона остаются: профиль входит только персонажу заказчика и только пока отметка стоит. Внутренняя команда профиль не читает. Пока исполнитель один и это владелец, запись профиля одна.

| № | Блок | Исполнитель | Чем проверяется |
|---|---|---|---|
| 1 | У двух назначенных исполнителей во вход своей сессии попадает свой профиль и не попадает чужой | родитель | `node --test test/profile.test.ts` |
| 2 | Единственный профиль владельца читает персонаж его сессии | родитель | `node --test test/profile.test.ts` |
| 3 | Пустой профиль исполнителя не заменяется профилем владельца | родитель | `node --test test/profile.test.ts` |
| 4 | Прежняя строка профиля остаётся профилем владельца, проект рядом не стирается | родитель | `node --test test/profile.test.ts` |
| 5 | Полная проверка | dsh | `npm run verify` |

Блоки 1–4 у родителя: смысл критериев в одном модуле ядра. Блок 5 сделал родитель: дословный вывод `npm run verify` нужен в теле pull request.
