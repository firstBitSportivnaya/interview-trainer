# Issue 26 — граф связей таблицы

Шов — ядро `openTrainer`: текст, который уходит в записанную модель, когда персонаж составляет вопрос. Записанный порт эмбеддингов решает близость. Живой модели нет.

Связь берётся только из файла таблицы (имя `.xlsx`, сетка столбцов). Число ячейки в связь не входит. Абзац и pdf ребра не дают. Досье сильнее: утверждение «ограничения по весу нет» связь про вес не отдаёт. Слой по-прежнему называет владелец. Заказчик не получает служебный слой и шпаргалку проекта.

| # | Блок | Исполнитель | Чем проверяется |
|---|---|---|---|
| 1 | Таблица материала: тип паллеты связан с максимальным весом, досье о весе молчит. Вопрос про паллету может опереться на вес и не содержит числа из таблицы | родитель | `node --test test/graph.test.ts` |
| 2 | Та же таблица, досье говорит, что ограничения по весу нет. Связь про вес во вход не входит | родитель | `node --test test/graph.test.ts` |
| 3 | Та же связь только в абзаце и в pdf. При подготовке поиска ребра нет | родитель | `node --test test/graph.test.ts` |
| 4 | Полный прогон | dsh | `npm run verify` |
