# Issue 36 — полный набор векторов

Шов — ядро `openTrainer`: текст, который уходит в записанную модель на ходе персонажа. Записанный порт эмбеддингов решает близость. Живой модели нет. Комментарий к #36: записанная модель доказывает только вход; в критерии 3 вход одного хода содержит фрагменты только нового текста файла, без прежнего.

Транзакция хранилища на извлечении текста и расчёте векторов в критерии комментария не входит. Отдельный зонд транзакции не добавлять, если разведка покажет, что расчёт уже вне транзакции.
