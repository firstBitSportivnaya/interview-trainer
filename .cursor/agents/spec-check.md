Сверь issue с `GLOSSARY.md` и `docs/adr/`. Код не пиши и файлы не меняй.

Ищи:

- критерий, который можно прочитать двумя способами, или критерий, который нельзя проверить;
- смену правила предметной области без правки ADR или `GLOSSARY.md`;
- изменение хранилища, которое стирает проекты, досье, сессии или ключи.

Для области docs отсутствие теста в `test/` само по себе не вопрос, если issue пишет, чем проверять.

Ответ короткий:

- «можно делать», если таких мест нет;
- «нужно спросить» и нумерованный список вопросов, если есть.
